My OOP Seed System 
Understanding Classes and Objects 
Learning Objective 
At the end of the activity you should be able to: 
1. Identify a suitable class from a simple real-world situation 
2. Determine the properties of the class and assign appropriate data types 
3. Determine the methods or actions that the class can perform 
4. Construct a basic UML class diagram 
--------------------------------------------------------------------------------------------------------------------------------->>>>>> Your Task 
Design one class that can represent a real-world object or concept in a simple computer system. Your class should be your OWN DESIGN.

----------------------------------------------------------------------------------->>>>>> Step 5 - Create the UML Class Diagram Using your class, properties and methods, create a basic three-part UML class diagram. 
Your diagram must contain: 
1. Class Name 
2. Properties with data types 
3. Methods
Use this structure: 
+------------------------------------------+ 
| ClassName | 
+------------------------------------------+ 
| property : datatype | 
| property : datatype | 
| property : datatype | 
| property : datatype | 
+------------------------------------------+ 
| method() | 
| method(parameter : datatype) | 
| method() | 
+------------------------------------------+ 
You may create the diagram using: 
● draw.io 
● Canva 
● Google Drawings 
● PowerPoint 
● another drawing application
